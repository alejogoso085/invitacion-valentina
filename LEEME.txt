INVITACIÓN WEB - VALENTINA LÓPEZ GIRALDO

Archivos:
- index.html: página web completa.
- valentina.png: fotografía que aparece en la sección de presentación.
- referencia-diseno.png: imagen de referencia visual (no se usa como fondo de la web).

PARA ACTUALIZAR GITHUB:
1. Abre el repositorio invitacion-valentina.
2. Entra en Add file > Upload files.
3. Sube index.html y valentina.png.
4. Si GitHub pregunta por sobrescribir index.html, confirma que deseas reemplazarlo.
5. Pulsa Commit changes.
6. Espera unos minutos y abre https://alejogoso085.github.io/invitacion-valentina/

NOTAS:
- Los botones de Google Maps usan los enlaces proporcionados.
- La confirmación abre WhatsApp al número indicado.
- La página está diseñada para adaptarse a móviles y escritorio.
- La fotografía está enmarcada dentro de la sección de presentación, entre la portada y el mensaje.
